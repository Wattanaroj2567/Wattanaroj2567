## FallHelp

FallHelp is my senior project for safer, faster caregiver response. It connects a neck-worn ESP32 device with a caregiver mobile application through a real-time backend.

- Wearable fall detection using accelerometer and gyroscope data
- Heart-rate capture when a possible fall is detected
- MQTT and Socket.IO event flows for alerts and acknowledgement
- React Native and Expo mobile experience for caregivers
- Backend API, PostgreSQL, push notifications, and admin operations

→ [View the FallHelp repository](https://github.com/Wattanaroj2567/fallhelp)
